# Patient Priority Scheduler (AVL Tree)

This is a Java project from my Data Structures class. It uses an AVL tree to keep patient records organized by priority.

## What it does
- Adds patients with their priority values
- Removes patient records
- Uses AVL tree balancing to manage the data
- Prints the patient schedule and identifies the highest-priority patient

## What I used
Java, AVL trees, binary search trees, recursion, and tree rotations.

## How to run
```bash
javac PatientScheduler.java PatientSchedulerDemo.java
java PatientSchedulerDemo
```

## About this project
This was a class assignment and uses sample patient data. It is not a real medical scheduling system.
